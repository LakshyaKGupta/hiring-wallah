Semantic CSS Classes Used (from globals.css):

    • Font: var(--font-sans) [NOT monospace]
    • Size: var(--text-caption) [0.75rem]
    • Weight: var(--weight-body-medium) [500]
    • Case: Sentence case [NOT uppercase]
    • Purpose: UI labels, badges, helper text

  .type-mono-score
    • Font: var(--font-mono)
    • Weight: 500
    • Features: font-variant-numeric: tabular-nums
    • Purpose: Numeric glyphs, scores, terminal output only

  .type-caption
    • Font: var(--font-sans)
    • Size: var(--text-caption)
    • Weight: var(--weight-body-medium)
    • Case: Sentence case
    • Purpose: Small helper text, secondary labels

================================================================================
DESIGN IMPACT
================================================================================

BEFORE:
  ❌ Uppercase labels looked like code/system messages
  ❌ Monospace overuse made UI feel "generated" or AI-created
  ❌ No visual distinction: utility labels = terminal output
  ❌ Poor readability of lowercase text in monospace

AFTER:
  ✅ Clear hierarchy: brand moments stay uppercase, labels use sentence case
  ✅ Terminal contexts ONLY use monospace (more authentic)
  ✅ Improved accessibility (better screen reader handling)
  ✅ Human-designed feel: proper semantic typography
  ✅ Better label readability with sans serif
